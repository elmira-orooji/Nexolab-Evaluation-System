# معماری NexoLab

هستهٔ برنامه شامل مدل‌های دامنه و هماهنگ‌کنندهٔ اجرای آزمون است. آداپترها انتقال HTTP، خواندن فایل و نوشتن گزارش را انجام می‌دهند. وابستگی‌ها از بیرون به هسته می‌روند. `bootstrap.py` محل انتخاب و اتصال پیاده‌سازی‌های واقعی است.

`domain/models.py` مدل‌های TestCase، EvaluationSuite، RagResponse، CaseResult و EvaluationRun را تعریف می‌کند. پاسخ استاندارد و پاسخ خام سرویس هر دو در RagResponse وجود دارند. گزارش نسخهٔ اول و CLI قبلی حفظ شده‌اند؛ `runner.py` فقط ورودی سازگار برای فراخوان‌های قبلی است.

`application/ports.py` قراردادهای کوچک RagAdapter، RunStore و ReportExporter را با Protocol تعریف می‌کند. EvaluationRunner به RagAdapter و RunStore وابسته است. صادرکنندهٔ گزارش پس از پایان اجرا در bootstrap فراخوانی می‌شود. اضافه‌کردن سرویس جدید فقط به یک آداپتر و انتخاب آن در bootstrap نیاز دارد.

`application/evaluators.py` پس از پاسخ موفق، معیارهای قطعی پوشش اسناد مرجع و precision/recall/F1 استناد را محاسبه می‌کند. ارزیابی معنایی DeepEval با متغیر محیطی `NEXOLAB_EVALUATION_ENGINE=deepeval` و نصب extra اختیاری فعال می‌شود؛ در حالت پیش‌فرض داده‌ای به مدل بیرونی فرستاده نمی‌شود. خروجی معیارها در هر نتیجهٔ مورد ثبت می‌شود و صفحهٔ تحلیل میانگین هر معیار را نشان می‌دهد. معیارهای قطعی به `expected_document_ids` نیاز دارند و ارزیابی معنایی نیز وابسته به مدل داور و دسترسی ارائه‌دهنده است.

قرارداد پاسخ‌گویی آداپتر `answer(case, request) -> RagResponse` است. request، درخواست مؤثر با تنظیمات بازنویسی‌شدهٔ هر مورد است. آداپتر باید خطای قابل انتظار سرویس را به AdapterError تبدیل کند. هسته فقط این خطا را خطای مورد می‌داند و ادامه می‌دهد؛ خطای برنامه‌نویسی یا شکست ذخیره‌سازی به فراخواننده منتقل می‌شود. در JSON، response فیلدهای استاندارد پاسخ را دارد و raw_response پاسخ اصلی سرویس را بدون تبدیل نگه می‌دارد. در Nexora این دو معمولاً یکسان هستند.

فقط config اعتبارنامه را از محیط می‌خواند و bootstrap آن را به NexoraAdapter تزریق می‌کند. اعتبارنامه بخشی از مدل اجرا یا تنظیمات گزارش نیست. json_loader ساختار عمومی مجموعه را هنگام ورود بررسی می‌کند. محدودیت‌های اختصاصی درخواست Nexora در adapters/rag/nexora_validation.py هستند و فقط برای همین آداپتر اعمال می‌شوند. آداپتر Nexora پاسخ را هنگام دریافت اعتبارسنجی می‌کند.

JsonRunStore با فایل موقت و replace، checkpoint را جایگزین می‌کند تا شکست نوشتن فایل جدید، گزارش قبلی را ناقص نکند. این کار تضمین دوام در قطع برق نیست. CsvExporter مسئول تبدیل نتیجه به جدول و حفاظت در برابر فرمول spreadsheet است.

`bootstrap.prepare_run` اثرانگشت SHA-256 از snapshot نرمال‌شدهٔ مجموعه و تنظیمات می‌سازد و provenance محیط را به مدل اجرا تزریق می‌کند. اعتبارنامه از این داده‌ها حذف است؛ توکن فقط به آداپتر می‌رسد. `application.compare_runs` دو گزارش را به‌صورت قطعی مقایسه می‌کند و به HTTP یا رابط وابسته نیست. آداپتر وب فقط دو گزارش کامل را می‌خواند و نتیجهٔ مقایسه را عرضه می‌کند؛ هیچ نمره‌دهی با مدل زبانی انجام نمی‌شود.

تست‌های application با آداپتر، ذخیره‌ساز و ساعت جایگزین اجرا می‌شوند. تست معماری ورود وابستگی‌های زیرساخت به هسته را بررسی می‌کند. تست‌های HTTP و گزارش نیز رفتار بیرونی نسخهٔ قبلی را پوشش می‌دهند.

رابط وب با آداپتر محلی adapters/web به همان هسته وصل است. bootstrap.prepare_run یک اجرای آماده می‌سازد که CLI آن را مستقیم و سرویس وب آن را در worker اجرا می‌کند. جزئیات API و ذخیرهٔ نظرهای جدا از گزارش در [web-api.md](web-api.md) آمده است. این مسیر هیچ وابستگی HTTP به هسته اضافه نمی‌کند.

`json_loader.inspect_suite` خطاها و هشدارهای قالب را به‌صورت ساختاریافته جمع می‌کند و `validate_suite` برای اجرا خطاهای بحرانی را رد می‌کند. `JsonSuiteRepository` فقط فایل‌های JSON داخل پوشهٔ مجموعهٔ پیکربندی‌شده را می‌خواند و با نوشتن موقت و جایگزینی اتمی مجموعه‌ها را مدیریت می‌کند. هر اجرا snapshot مستقل مجموعه را می‌گیرد؛ تغییر بعدی فایل، گزارش قبلی را تغییر نمی‌دهد. دسته، سطح دشواری و برچسب‌ها در مدل آزمون و خروجی CSV ثبت می‌شوند.

رابط در `frontend/` یک برنامهٔ React مبتنی بر Vite است. `src/App.jsx` جریان صفحه‌ها و state را هماهنگ می‌کند، `src/components.jsx` اجزای مشترک و `src/api.js` ارتباط HTTP را نگه می‌دارند. ورودی‌های `index.html` و `brand.html` هر دو React هستند. build چندصفحه‌ای در `ui/` نوشته می‌شود تا سرور Python فایل‌های ثابت و API را از یک origin ارائه کند؛ وابستگی‌های Node در زمان اجرای بستهٔ Python لازم نیستند.
