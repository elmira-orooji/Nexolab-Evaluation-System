# نمونهٔ رابط NexoLab

از ریشهٔ مخزن اجرا شود:

```powershell
python -m http.server 8012 --bind 127.0.0.1 --directory ui
```

سپس آدرس `http://127.0.0.1:8012` را باز کنید. این نمونه به Nexora یا API اجرای آزمون وصل نیست. تمام پاسخ‌ها از پاسخ مرجع مجموعهٔ ساختگی آمده‌اند. ارزیابی در localStorage مرورگر نگهداری می‌شود و خروجی JSON جدا دارد. برای نظرها هنوز run_id واقعی وجود ندارد؛ فایل خروجی با prototype=true مشخص می‌شود.

نشانه و فونت‌ها از پروژهٔ مرجع Nexora، بدون تغییر کپی شده‌اند. نام محصول با متن NexoLab کنار نشانه قرار گرفته است؛ لوگوی مادر دست‌کاری نشده است. رنگ‌ها و شعاع گوشه‌ها از theme.css مرجع گرفته شده‌اند. cases.json نسخهٔ نمایشی مجموعهٔ آزمون است و هنگام تغییر مجموعه باید به‌روز شود.

برای این نمونه ابزار build و وابستگی npm لازم نیست. فایل‌های app.js، styles.css و index.html به‌ترتیب مسئول تعامل، ظاهر و ساختار هستند. ارزیابی‌ها با ثبت صریح ذخیره می‌شوند؛ پیش‌نویس با رفتن به پرسش دیگر در حافظه حفظ می‌شود، اما با بستن یا بارگذاری مجدد صفحه از بین می‌رود و در خروجی ارزیابی‌ها نیست.
