# رابط متصل NexoLab

نصب بسته و اجرا از ریشهٔ مخزن:

```powershell
python -m pip install -e .
nexolab --serve --suite datasets/persian.synthetic.json --config configs/fixture.json --output runs --port 8013
```

آدرس `http://127.0.0.1:8013` را باز کنید. اجرای آزمون، مشاهدهٔ پیشرفت هر مورد، منابع و ارجاع‌ها، تاریخچهٔ اجرا، دریافت گزارش JSON و CSV و ثبت ارزیابی دستی به API واقعی Python متصل‌اند. اجرای fixture صریحاً برچسب دارد و پاسخ مرجع را بازمی‌گرداند؛ برای ارزیابی کیفیت Nexora مناسب نیست.

برای Nexora، از configs/nexora.example.json یک فایل configs/nexora.local.json بسازید. base_url و UUID مجموعهٔ آزمون در request.document_set_id را تنظیم کنید. توکن نشست معتبر باید در متغیر محیطی NEXORA_TOKEN فرایند سرور باشد؛ توکن در مرورگر وارد یا ذخیره نمی‌شود. سپس دستور بالا را با --config configs/nexora.local.json اجرا کنید. پیش‌نیاز این اتصال، اجرای Nexora و نمایه‌سازی اسناد آزمون است.

پارامتر --ui-directory مسیر فایل‌های رابط را مشخص می‌کند و پیش‌فرض آن ui نسبت به پوشهٔ جاری است. بازکردن مستقیم index.html یا استفاده از python -m http.server دیگر برای این رابط کافی نیست. سرور و فایل‌های رابط روی یک origin هستند؛ CORS فعال نیست.

فقط یک آزمون هم‌زمان در هر فرایند سرور اجرا می‌شود. سرور فقط روی 127.0.0.1 گوش می‌دهد و برای استفادهٔ محلی است؛ سرویس عمومی یا چندکاربره نیست. Host، Origin و header اختصاصی برای درخواست‌های تغییردهنده بررسی می‌شوند. از اجرای دو سرور با پوشهٔ خروجی یکسان خودداری کنید. بستن سرور می‌تواند اجرای جاری را قطع کند؛ checkpoint باقی می‌ماند و پس از راه‌اندازی مجدد اجرای ناقص با برچسب interrupted دیده می‌شود. ادامهٔ خودکار اجرا وجود ندارد.

نظرها در runs/<run_id>/reviews.json جدا از report.json ذخیره می‌شوند. ثبت هر نظر به run_id و case_id مربوط است و زمان UTC دارد. خروجی «دریافت ارزیابی‌ها» این شناسهٔ اجرا را هم دارد. حذف نظر فقط فایل ارزیابی را تغییر می‌دهد؛ گزارش اصلی دست‌نخورده می‌ماند. پیش‌نویس ثبت‌نشده فقط در حافظهٔ صفحه است و با تغییر اجرا یا بارگذاری مجدد از بین می‌رود. نظرهای نمونهٔ قدیمی localStorage به اجراهای واقعی منتقل نمی‌شوند.

فایل app.js مسئول state و نمایش صفحه و client.js مسئول ارتباط HTTP است. فایل cases.json فقط نسخهٔ قدیمی دادهٔ نمایشی است و رابط اکنون مجموعه را از سرور می‌خواند. نشانه و فونت‌ها بدون تغییر از Nexora آمده‌اند. گزارش‌ها و نظرها ممکن است متن خصوصی داشته باشند و در Git نادیده گرفته می‌شوند.
